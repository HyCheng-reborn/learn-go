# 01 - Array：赋值会复制整个数组

核心例子：

```go
a := [3]int{10, 20, 30}
b := a
b[0] = 999
```

输出中：

```text
a: [10 20 30]
b: [999 20 30]
```

## 为什么

Go 的 array 是值类型。

```text
a ----> [10 20 30]

b := a

得到：

a ----> [10 20 30]
b ----> [10 20 30]
```

不是让 `b` 指向 `a`。

## 和 slice 的关键对比

array：复制数据本身。

slice：复制的是一个描述底层数组的“小结构”，两个 slice 可能仍共享同一底层数组。
